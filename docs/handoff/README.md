# Handoff log

- `00_project_overview.md` — stable project facts (architecture, optics, wiring, parts, to-dos). Paste into a new chat to resume.
- One file per working day: `YYYY-MM-DD.md` with **Done / Issues / Fixes / Next / Commits**.
  - **Commits** is filled automatically by `scripts/githooks/post-commit` (run `scripts/install_hooks.sh` once per clone).
  - Done / Issues / Fixes / Next are written at the end of each session (Claude Code does this per CLAUDE.md §5).
- Find past fixes fast: `grep -A3 "## Fixes" docs/handoff/*.md`
